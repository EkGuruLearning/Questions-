# Correction Note — Repeater and Topology

**Original:** “The repeater is used in ___ topology.”  
**Expected basic-textbook answer:** Ring topology.

**Why the stem needs correction:** The wording sounds as though a repeater is used only in ring topology. A repeater is a Physical Layer device that regenerates/reshapes a signal and can be used on multiple kinds of transmission links. The ring answer relies on the classic ring-network model in which a station regenerates and forwards the signal.

**Corrected MCQ**

In a traditional ring network, repeaters are particularly associated with which topology because each station can regenerate and forward the signal?

(A) Ring topology  
(B) Mesh topology  
(C) Bus topology  
(D) Star topology

**Correct answer: (A) Ring topology.**

**Explanation:** In a classic ring, each station commonly regenerates/repeats the incoming signal before passing it to the next station. Repeaters are not exclusive to ring networks; this qualification avoids a misleading universal claim.
